# NexBash Redesign (temp2)

Standalone redesign of the NexBash marketing site. The original project is untouched.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Highlights

- Futuristic multi-layer cursor follower (core + lagging ring + glow trail)
- Hover modes: expand on cards, CTA pulse, brand dashed ring, magnetic studio cards
- Atmospheric hero with mesh, orbs, and scan motion
- Clean sections: studios, work, process, packages, FAQ, contact
